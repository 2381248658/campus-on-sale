## 🔧 接口通用说明

### 请求头

- `Content-Type`: `application/json`
- `Authorization`: `Bearer {token}` (需要认证的接口)

### 响应格式

```typescript
ApiResponse<T> = {
  code: string, // 响应码
  msg: string, // 响应消息
  result: T, // 响应数据
};
```

### 状态码说明

- `200`: 请求成功
- `400`: 请求参数错误
- `401`: 未授权
- `404`: 资源不存在
- `500`: 服务器内部错误

### 订单状态码

- `0`: 全部订单
- `1`: 待支付
- `2`: 已支付
- `3`: 已发货

### 热销榜单类型

- `1`: 24小时热销榜
- `2`: 周热销榜

### 排序字段

- `publishTime`: 发布时间
- `orderNum`: 订单数量
- `evaluateNum`: 评价数量
